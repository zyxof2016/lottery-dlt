# 号码池与排序 1.11.0

排序的目标改成缩短盖住全部开奖号的号码池。前区要盖住 5 个，后区要盖住 2 个。名次只使用目标期之前的开奖，不是中奖概率，也不改已经保存的方案。

热号、冷号、遗漏、跟随上期、避开上期和分区轮动仍按原来的方向打分。每一期开奖后，只额外把“排在最后的那个开奖号”往前提，因为它决定了号码池要拉到多长。下一次排序时，这个号码和原来的方向分一起比较。

另外四行只服务这个目标：

- 覆盖瓶颈：按各方向里曾经垫底的开奖号汇总，垫底越频繁越靠前。
- 同出补齐：垫底的号码优先，和它同一期开出的其余号码也略提前。
- 全覆盖融合：哪一种方向最近用更短的前缀盖住开奖号，下一次就给它更高的权重。
- 近期全覆盖：同样统计垫底号码，但更早的记录衰减更快。

均匀随机对照不参与这项调整，继续用来对照理论期望。前区全覆盖期望仍是前 30 名，后区仍是前 2×13/3 名。待开奖的覆盖留空，不记成 0。
