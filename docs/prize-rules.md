# 大乐透规则依据

本项目在2026年10月15日核对以下体彩机构资料，按期号选择奖表，不以当前奖级倒算旧期开奖。

- [中国体育彩票超级大乐透游戏规则](https://m.lottery.gov.cn/ksjz/m/yxgz_dlt/)：现行双区选号、追加、七奖级、8亿元开奖前奖池分档。
- [体彩官方计算器](https://m.lottery.gov.cn/mltsz/jsq/index.html)：明确26014期起变更规则。
- [广东体彩26014期开奖公告](https://www.gdlottery.cn/f_html/kjgg/P085_26014.html)：2026年2月2日开奖号码和基础奖金，用于固定测试样本。
- [江苏体彩19019期开奖公告](https://www.js-lottery.com/cms/post-86898.html)：2019年2月20日九奖级公布金额，用于核对旧版固定奖表。

## 中奖条件映射

`前+后` 指单注与当期开奖相同的前后区号码数量。每注只取对应的一个奖级。

| 命中 | 2019九奖级 | 2026七奖级 |
|---|---|---|
| 5+2 | 一等奖 | 一等奖 |
| 5+1 | 二等奖 | 二等奖 |
| 5+0 | 三等奖 | 三等奖 |
| 4+2 | 四等奖 | 三等奖 |
| 4+1 | 五等奖 | 四等奖 |
| 4+0 | 七等奖 | 五等奖 |
| 3+2 | 六等奖 | 五等奖 |
| 3+1 / 2+2 | 八等奖 | 六等奖 |
| 3+0 / 2+1 / 1+2 / 0+2 | 九等奖 | 七等奖 |

## 核算约定

各期公告的奖额优先于标准奖表。2026固定奖标准推算必须有已核实的开奖前奖池；未提供时保留金额未知。历史接口可能只返回开奖结果和开奖后的滚存奖池，后者不能作为本期8亿元门槛的依据。

追加只增加一、二等奖奖金；追加金额使用当期公布值，固定奖不因追加增加。派奖资格、销售网点活动、特殊限额赔付、税务和兑奖期限不从标准票面自动推断。研究中的固定奖期望只涵盖标准固定奖，不代表总期望或收益承诺。

浮动奖缺失时，中奖注数照常统计，方案总奖金和净收益为未知。不会因为某期未公布单注金额、零中出或追加为 `---` 而将可能中奖的方案记为0元。
