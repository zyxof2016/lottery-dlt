# 号码池与排序 1.10.0

首页改为号码池与排序。前区 1–35 选 5、后区 1–12 选 2，各自按热号、冷号、遗漏、跟随上期、避开上期、分区轮动和均匀随机对照排序。

排序只使用目标期之前的开奖。热号和冷号是同一出现次数的两个方向。名次不是中奖概率，也不改写已经保存的方案。

已开奖期显示开奖号在名次上的位置、盖住 3/4/5 个前区号或 1/2 个后区号所需的最短前缀，以及前 5 名、前 2 名里有几个开奖号。均匀对照的全覆盖期望是前区 30、后区 2×13/3。历史平均跳过第一期，待开奖的覆盖留空，不记成 0。

冻结号码池是这一期已经保存的方案。可以按方案名筛选，并按号码数、覆盖开奖号或方案名排序。其他期的方案不会混进来。

开奖历史和系统设置仍在导航里。生成、复盘和实验页面不再作为入口；已保存方案和开奖记录保留。
