# 1.3.0：预算增量、删号诊断与复盘易用性

本轮参照本地 `lottery-k8` 截至2026-10-23的预算增量复盘、交集门槛诊断与易用性改进，适配大乐透前区35选5、后区12选2。版本为1.3.0，继续使用 `dlt-plan-v3`，原有归档及选号算法不重建，无数据库迁移。

## 实际预算增量

“每期推荐与复盘”新增“实际预算增量复盘”，可直接打开 `/dlt/reviews#budget-increments`；没有代理前缀时去掉 `/dlt`。

仅从同一期整期推荐清单内合格的实际原票组构成比较。先按成本、注数、清单名称和原始身份固定方向，不按开奖命中或奖金选择比较对象。每对记录保存：

- 两侧成本、增加投入及原始方案ID。
- 前后区分别新增、丢弃的号码，以及它们实际命中的开奖号。
- 并集覆盖增量、每增加一元的覆盖增量；同成本时每新增元指标为 `null`。
- 完整5+2单注的新增／移除注数，分别检查“两区并集保留”和“完整票组保留”。
- 奖金差与净额差；任何一侧奖额未知时完整金额差为 `null`。

共同期均值只纳入双方均有合格已开奖档案的期号。待开奖、缺档和排除项不计零分。奖额完整子集单列期数、成本增量和净额差，不与全部期次的成本混算。导出保留各期新增、丢弃命中及原始票组链接；点击链接按期号定位原票组。

复盘同时给出票组的两区位置总数、实际并集、重复位置及并集上界。上界为 `min(35, 前区位置数)` 与 `min(12, 后区位置数)`，不含额外复式、胆拖或固定池限制，不表示中奖率或收益最优。保留两区并集可能移除完整5+2单注，因此不能作为“无损减少投注”的依据。

数据作为新增 `budget_increments`、逐期 `budget_comparisons` 及逐方案 `capacity` 字段，包含在现有 `GET /api/recommendations/live-review?limit=30` 中；复盘响应格式版本升为2，原有字段保留。

## 交集删号诊断

号码池可选择一个参考池，逐一显示1～所选池数的所有频次门槛。每个门槛分别列出前后区完整号码、命中、均匀参考期望、相对参考池丢弃的号码及已命中号。严格交集只是最高门槛，不默认认定它比其他门槛更准确。

均匀参考期望为 `前区池数 × 5/35`、`后区池数 × 2/12`。实际“入选号命中比例”与“开奖号覆盖率”分别计算；未开奖或读取失败时保留未知，空池的入选号命中比例为未知。这些是集合与事后诊断，不是预测概率。

本页支持按来源名称、期号、身份及“前区N／后区N”搜索。批量选择只勾选当前页的筛选结果，跨期选择保留；“取消全部勾选”只清除当前标签页的选择。新增复制交集及复制失败反馈，购买票组仍以原始逐注记录为准。

JSON分析格式版本升为2，包含全部门槛和删号诊断；JSON／CSV继续导出全部并集行，不受显示门槛影响。现有会话选择格式版本1仍可读取，仅增加可选参考池标识。

## 页面组织与错误恢复

原始票组与逐注对奖排在持续统计和池分析之前，增加原票组、持续复盘、预算增量、号码池任务链接，原有深链接继续可用。

原始推荐与辅助复盘独立请求。辅助复盘失败显示错误和重试入口，原票组继续可查看；加载新来源时清除旧来源显示，失败保留已选池，并禁止用旧数据批量勾选。开奖对照区分读取中、缺缓存、失败和已读取；读取失败不复用此前命中标记。

来源、开奖及复盘加载均核对请求序号与页面版本，防止迟到响应覆盖新选择，包含“A期→B期→A期”的情况。所有宽表支持键盘聚焦和方向键滚动。修复375px手机下输入框、网格及长文本撑宽页面的问题。

小概率使用科学记数法保持非零，例如单注头奖概率显示 `4.67e-6%`；接近1但未等于1时显示 `>99.99%`。配对负差保留负号，未知显示“—”，不再与零混淆。
